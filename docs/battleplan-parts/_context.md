## Settled decisions (Siang Woo leads; do not change)
- Crew app for astronauts. Minimal UI text, numbers first. Explanations live in slides or an optional separate explainer site, never in the app.
- Body map is home. Tapping a region opens that region's risk tab(s). Body map will be cuter and more interactive (options designed separately in design/body-map-options.html).
- Results are pattern matches or change vs the person's own baseline. Never a diagnosis. Never write "healthy", "safe", "cleared", diagnosis, treatment or prescription wording.
- Each risk tab has its own input method AND its own best-fit display (not one template). Example: sleep = line graph across the night.
- Ownership: Shi Wei = risks 1–4. Siang Woo = risks 5–8 + optional Mood, and owns the astronaut vector.
- Tabs never read each other's internals. Each tab emits a small signals record; the astronaut vector (owned by Siang Woo) collects them and gives each tab personalisation (traits, baselines, exposures, reasons).
- Presentation: 7 slides + 30-second clip.
- Polish bar: headlines <= 6 words; labels/buttons <= 3 words; no paragraph over one sentence on main screens; mono font only for values/units/IDs/times; orange accent only for primary action / current selection; status never by colour alone; works at 320 px; simulated data always tagged "Simulated"; footer "Prototype · not for clinical use"; missing values stay null, never 0.

## Risk tabs
1 Cardiovascular (Shi Wei). NASA risks: Reduced cardiorespiratory fitness + Cardiovascular adaptations. Input: exercise session readings (HR at fixed workload) + VO2peak reports. Display: baseline vs latest dot chart; VO2 trend with 80% line (both exist). Metrics: HR at same workload (bpm); VO2peak % of baseline; Borg effort 6–20; resting HR; missing readings count. Eval example: "100 W: +41 bpm vs your baseline · 74% capacity retained". Data: NASA MR080G https://nlsp.nasa.gov/search/data/details/852cd84a-464d-572b-99ac-9555f4dda464?dataType=DATASETS (real, in use). Label VO2peak, never VO2max.
2 Sleep (Shi Wei). Input: wearable sleep data or morning check-in. Display: line graph across the night (stage/movement) with shift-schedule overlay; 24 h view. Metrics: hours slept; sleep efficiency %; Karolinska Sleepiness Scale 1–9; Samn-Perelli fatigue 1–7; body-clock shift (h). Eval: "Sleep debt 6.5 h over 3 days". Data: Sleep-EDF Expanded https://www.physionet.org/content/sleep-edfx/1.0.0/ (ODC-By).
3 Immune (Shi Wei). Input: photo upload + symptoms. Display: photo beside closest reference patterns with match bars. Metrics (from Urticaria Activity Score): wheal count 0–3 (0 none, 1 <20, 2 20–50, 3 >50); itch 0–3; shape (raised, clear edges, pale centre) yes/no; fades within 24 h yes/no; spread across body areas count. Eval: "Hives pattern 80% · ↑ known shellfish allergy, shellfish eaten 3 h ago". Consumes Food signals + vector allergies. Data: Google SCIN https://github.com/google-research-datasets/scin (own data-use licence; no re-identification; hives coverage unverified) + USDA FoodData Central. Alcohol is banned on the ISS (ethanol harms water recovery), so the demo trigger is a food allergen (shellfish).
4 Bone (Shi Wei). Input: pre/post-flight DXA results (entered by medical team) + exercise logs. Display: skeleton map coloured by % change per site. Metrics: BMD change %/month per site; resistance load % of plan; calcium mg + vitamin D IU intake; sodium mg; days in flight. Eval: "Hip −1.2%/month · resistance load 70% of plan". Data: NHANES DXA https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2013/DataFiles/DXXSPN_H.htm ; NASA LSDA by request.
5 Balance / sensorimotor (Siang Woo). Input: 30-s stand test holding tablet to chest (device motion sensors measure sway) + dizziness and motion-sickness ratings. Display: live sway trace with area ellipse vs baseline. Metrics: sway area eyes open; sway area eyes closed; dizziness 0–10; motion sickness 0–20; head-movement tolerance 0–3. Eval: "Eyes-closed sway 2.1× your baseline". Data: Human Balance Evaluation Database https://registry.opendata.aws/hbedb/ (ODC-By).
6 Microbiome (Siang Woo). Input: gut check-in (Bristol stool 1–7, bloating, appetite), skin-infection photo, antibiotics. Display: gut timeline with Bristol strip. Metrics: Bristol type 1–7; bloating/pain 0–3; fibre g/day; antibiotics in last 14 d yes/no; skin infection signs 0–3. Eval: "Gut pattern changed 4 days · low fibre since day 12". Data: NASA ISS microbial data on OSDR (e.g. OSD-252) + SOMA https://soma.weill.cornell.edu/apps/SOMA_Browser.
7 SANS (Siang Woo). Input: on-screen Amsler grid test, near-vision test, headache rating; OCT results from medical team. Display: grid result + vision trend + OCT change. Metrics: Amsler distortion 0–3; near-vision change (lines); headache 0–10; OCT swelling change (µm); sodium mg + cabin CO₂ mmHg. Eval: "Near vision −0.5 vs baseline". Vector: genetic risk flag (B-vitamin one-carbon metabolism variants studied by NASA), baseline OCT. Data: crew OCT not public; OSDR mouse retina study; vision tests run in-app.
8 Food & nutrition (Siang Woo). Input: meal photo or ISS menu pick list matched to FoodData Central. Display: nutrient rings vs daily target. Metrics: energy % of need; protein g/kg; sodium mg; calcium mg + vitamin D IU; body-mass trend kg. Eval: "Energy 78% of need for 5 days · −1.4 kg". Feeds Immune (allergens), Bone, SANS, Microbiome, Cardio. Data: USDA FoodData Central https://fdc.nal.usda.gov/download-datasets.html (CC0; allergens only in ingredient text).
Optional Mood (Siang Woo). Input: 20-s daily sliders (NeuroVAS-style) + workload/conflict flags. Display: calendar heatmap of mood vs workload. Metrics: mood 0–10; stress 0–10; workload 0–10; isolation 0–10; crew conflict yes/no. Data: HERA Standard Measures https://nlsp.nasa.gov/explore/home/lsda_sm_hera (by request).
